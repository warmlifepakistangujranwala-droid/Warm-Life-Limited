# Warm Life Ltd — Project Roadmap

## Project Goal

Build a production-ready website platform containing:

- Public multi-page website
- Secure admin panel
- Content management system
- Service management
- Media library
- SEO manager
- Warm Life-only AI chatbot
- Leads and CRM tools
- Analytics and audit logs

## Delivery Phases

### v0.1.0 — Project Foundation
- Documentation
- Folder structure
- Environment configuration
- Git workflow
- Coding standards

### v0.2.0 — Admin Authentication
- Supabase connection
- Secure admin login
- Session handling
- Protected admin routes
- Logout

### v0.3.0 — Admin Dashboard
- Dashboard layout
- Navigation
- Light and dark mode
- Summary cards
- Activity panel

### v0.4.0 — Homepage CMS
- Hero management
- Section visibility
- Text, links, media and layout controls
- Certifications logo slider
- Partners logo slider
- Reviews and CTA management

### v0.5.0 — Services CMS
- Add, edit, delete and reorder services
- Dynamic service pages
- Homepage scroll-service selection
- Images and videos
- Service SEO

### v0.6.0 — Media Library
- Upload and organise images, videos and documents
- Alt text and metadata
- Usage tracking

### v0.7.0 — SEO Manager
- Metadata
- Canonical URLs
- Open Graph
- Schema
- Sitemap
- Robots controls

### v0.8.0 — AI Chatbot
- Warm Life-only knowledge base
- RAG-based answers
- Refusal of unrelated questions
- Lead capture
- Admin-managed prompts and limits

### v0.9.0 — CRM and Leads
- Lead inbox
- Statuses and notes
- Source tracking
- Export
- Admin activity logs

### v1.0.0 — Production Release
- Security review
- Performance review
- Accessibility review
- Final testing
- Production launch
